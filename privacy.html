Privacy Policy

Last updated: September 28, 2026

What data the tool handles

The tool only handles data about the single TikTok account that authorized it — the creator's own account:

  • the OAuth access and refresh tokens issued by TikTok, used to publish;
  • the account's open ID and granted scopes;
  • the creator information returned by TikTok before each post (username, nickname, available privacy levels), used to choose a privacy level that the account allows;
  • the identifiers of the videos it published.

It does not collect any data about other TikTok users.

Where it is stored

Everything is stored on the creator's own server, at home. Tokens are kept in a file readable only by the server account that runs the tool. Nothing is sent to any third party other than TikTok itself. The captions are written by a language model running on the creator's own hardware.

How long it is kept

Tokens are kept until they expire or until access is revoked. Video files are deleted from the server 30 days after publication.

Revoking access and deleting data

Access can be revoked at any time from the TikTok app: Settings and privacy → Security → Manage app permissions. The stored tokens then stop working and are deleted from the server.
