Terms of Service

Last updated: September 28, 2026

1. What this service is

Chess Shorts Publisher ("the tool") is a personal, self-hosted tool that renders chess puzzle videos and publishes them to the TikTok account of the creator who operates it. It is not offered to the public and has no user accounts.

2. Use of TikTok

The tool uses TikTok Login Kit and the Content Posting API only to publish videos to the account that explicitly authorized it. Using the tool does not change TikTok's own Terms of Service and Community Guidelines, which apply to every published video.

3. Content

Videos are generated by the creator's own software. Chess puzzles come from the Lichess puzzle database, released under CC0. Captions are written by a language model running on the creator's own hardware. The creator is responsible for everything published to their account.

4. Revoking access

Access can be revoked at any time from the TikTok app: Settings and privacy → Security → Manage app permissions. Once revoked, the tool can no longer publish.

5. No warranty

The tool is provided as is, without warranty of any kind.

Questions can be raised on the project's issue tracker.
